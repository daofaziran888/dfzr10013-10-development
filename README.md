# 企业经营分析决策平台

面向企业高层管理的经营分析决策平台。覆盖经营指标看板、财务多维分析、销售漏斗洞察、客户画像构建、供应链效率监控、人力效能评估、经营预测模型、异常预警与决策建议推送的完整企业分析链路。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 同期对比差异数据

同期对比分析不再只是保存方案和示例字段，而是基于明细计算差异，产出可复核的数据集版本，
供经营分析报告生成数据附件。

- 指标目录：`backend/app/seed_compare.py` 的 `METRICS`，区分「可加」与「比率」；
  比率指标必须定义分子、分母（如 成交数/访问数、销售额/订单量）。
- 方案：选择指标、基准周期、对比周期、维度与对齐方式（`按日对齐` / `按整期`）。
- 明细：`POST /api/compare/{id}/details`，逐条记录业务日期、维度值、指标值、分子分母与上报状态。
  导入整体校验，任一行不合法则全部不写入；补报/更正会抬高方案明细修订号，旧值进入修订历史。
- 计算：`POST /api/compare/{id}/calculate`。计算在内存中完整算完后一次性发布新版本，
  中途失败或计算期间明细/配置发生变化，整次计算作废，不会把一侧新结果和另一侧旧结果拼成报告。
- 数据集：`GET /api/compare/datasets/{id}`，每个指标每个维度同时给出
  「原始统计范围」「实际参与比较范围」「未纳入部分」；`/trace` 可按指标+维度回溯原始明细，
  查看旧版本时明细会按当时修订号还原。
- 报告附件：`POST /api/report/{id}/attachments`，附件冻结周期、覆盖范围、汇总分子分母、
  来源版本与数据集快照；后续重算不会改变已生成的附件。

计算口径的几个硬约束：

- 未上报不等于 0：未上报明细不参与任何一期汇总，缺报与真实零值分别表达。
- 基准为零、两期均为零、缺报不可比、新增维度、消失维度、分母为零分别给出状态和原因；
  无法形成有效变化率时不给百分比。
- 可加指标按所选范围汇总；比率指标汇总分子分母后重算，不对明细百分比取平均，
  百分比口径的变化量以「百分点」表达。
- 长短月份按日对齐时，多出的日期列入未纳入部分；整期口径下周期天数不同则不计算可加指标变化率。
- 汇总的可比天数取所有参与维度中的「最窄可比天数」，覆盖不足不会被解释成经营下降。
